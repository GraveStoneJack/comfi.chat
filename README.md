# luxeonchat

A real time chat webapp providing you with a sophisticated chat experience. A high quality and aesthetically pleasing web interface. Giving you the opportunity to chat to strangers privately, make new friends or special connections. You have the option to register with a personalised profile and ensure your connections aren't forgotten or you can join anonymously without registration. 

## Installation
```
mkdir luxeonchat
cd luxeonchat
npm init -y
npm install express mongoose bcryptjs jsonwebtoken passport passport-google-oauth20 passport-apple dotenv cors
```
